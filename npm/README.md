# lq

A fast native clone of `shopify theme check` and the Liquid Prettier plugin. Not affiliated with or endorsed by Shopify.

```sh
npx lq check
npx lq fmt "**/*.liquid" --check
```

This package holds prebuilt binaries for macOS and Linux, on x64 and arm64. There's no install script, and nothing is
downloaded when it runs. See the project's README for usage, what's verified against upstream, and known gaps.
