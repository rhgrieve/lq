Theme Check and Liquid formatting, in one fast binary.

lq is a Rust port of Shopify's theme check and the Prettier Liquid plugin. No Node, no runtime, and it never touches the network.

Try it in the browser Install

Speed

Shopify's Horizon theme, 282 Liquid files. Median of 11 runs on an M3 Max.

CommandTimeRelative
lq check0.054s
shopify theme check3.380s
lq fmt --check0.025s
prettier --check1.956s

Linting is 63x faster and format checks are 78x faster.

Compatibility

  • All 91 checks. On Dawn, Horizon and a production theme, it reports the same offenses as theme check 3.31.0.
  • Same formatting as Prettier. Liquid and HTML output is byte-identical to prettier-plugin-liquid 1.11.3. Embedded JS and CSS go through Biome, which can differ in some cases.
  • Same JSON. lq check --output json matches upstream byte for byte, so existing tooling keeps working.
  • Upstream bugs fixed. 20 known bugs, each listed with a reproduction in DIVERGENCES.md. --upstream-bugs turns them back on.
  • Reads your config. .theme-check.yml, .prettierrc and ignore files work as they do today.

    Install
    
      
    Add the release tarball to package.json. It ships binaries for macOS and Linux (arm64, x64) and Windows (x64). There's no install script, and nothing is downloaded at run time.
    
      
    {
  "devDependencies": {
    "lq": "https://github.com/rhgrieve/lq/releases/download/v0.2.0/lq-theme-check-0.2.0.tgz"
  }
}
    
      
    Or build from source with a Rust toolchain:
    
      
    cargo install --git https://github.com/rhgrieve/lq lq-cli --locked
    

      
    Usage
    
      
    lq check                          # lint the theme in the current directory
lq check --auto-correct           # apply safe fixes
lq check --output json            # upstream's JSON
lq check --only OrphanedSnippet   # report one check
lq fmt "**/*.liquid" --check      # exit 1 if a file would change
lq fmt "**/*.liquid" --write      # rewrite in place
lq all --write                    # fixes, then formatting
    
      
    To swap it into an existing theme, replace shopify theme check with lq check and prettier with lq fmt in your scripts. The README covers CI, lefthook, report formats and the known gaps.
